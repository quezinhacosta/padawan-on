##  Sobre o Projeto

O **Padawan ON** é um sistema completo de gestão para o programa de apadrinhamento de calouros da UNICAP. A plataforma conecta **orientadores**, **mentores** e **calouros**, facilitando o acompanhamento acadêmico e a integração dos novos alunos ao curso de Ciência da Computação.

###  Objetivos

- **Integrar** calouros, mentores e orientadores em uma única plataforma
- **Facilitar** o acompanhamento do progresso acadêmico dos calouros
- **Gerenciar** grupos de mentoria e encontros
- **Automatizar** processos administrativos do programa
- **Promover** a integração e o suporte aos novos alunos

##  Funcionalidades

###  Para Orientadores (Administradores)
-  Dashboard com visão geral do programa
-  Gerenciamento completo de mentores
-  Gerenciamento completo de calouros
-  Formação e gerenciamento de grupos
-  Acompanhamento de encontros
-  Relatórios e estatísticas
- Configurações do sistema

###  Para Mentores
-  Dashboard personalizado
-  Visualização dos calouros atribuídos
- Acompanhamento do progresso dos calouros
-  Gerenciamento de encontros
- Controle de disponibilidade
-  Relatórios individuais

###  Para Calouros
-  Dashboard personalizado
- Informações do mentor
-  Visualização de encontros agendados
-  Acesso a recursos educacionais
-  Acompanhamento de progresso
- Comunicação com o mentor

###  Funcionalidades Gerais
- Sistema de autenticação com diferentes níveis de acesso
-  Dashboards interativos com estatísticas em tempo real
-  Agendamento e gerenciamento de encontros
-  Acompanhamento de progresso e frequência
-  Biblioteca de recursos educacionais
-  Log de atividades do sistema
-  Interface responsiva e moderna

##  Tecnologias

### Frontend
- **Next.js 14** - Framework React com SSR
- **React 18** - Biblioteca para interfaces
- **TypeScript** - Tipagem estática
- **CSS-in-JS** - Estilização com styled-components

### Backend (em desenvolvimento)
- **Node.js** - Runtime JavaScript
- **Next.js API Routes** - Endpoints da API

### Banco de Dados
- **PostgreSQL 16** - Banco de dados relacional
- **pgAdmin** - Interface de administração

### Ferramentas
- **Git** - Controle de versão
- **VS Code** - Editor recomendado
- **ESLint** - Linter de código
- **Prettier** - Formatador de código
